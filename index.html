Pago seguro con Wompi
Los datos de pago se ingresan directamente en Wompi. La tienda solo registra los datos necesarios para entregar tu producto y consultar el pedido.
⚠️ Antes de realizar el pagoVerifica cuidadosamente tu ID de jugador. Una vez realizada la recarga, no se realizan devoluciones por errores en el ID ingresado.
Importante sobre pago a crédito
Si eliges esta opción en Wompi, tus diamantes, pases, fragmentos, cajas u otros productos se entregarán únicamente cuando el pago esté completado y el dinero correspondiente haya sido confirmado para nuestra tienda. Mientras el pago esté pendiente, el pedido no será enviado a tu cuenta de Free Fire.

Preguntas frecuentes

¿Necesito registrarme para recargar?

No. Puedes realizar una recarga como invitado. Si tienes una cuenta, también podrás consultar tus compras desde tu historial.

¿Cómo consulto mi pedido?

Copia el número de referencia que recibirás después de completar el proceso de pago en Wompi y úsalo para consultar el estado.

¿Qué pasa si escribo mal mi ID?

Revisa cuidadosamente tu ID antes de pagar. Las recargas realizadas a un ID incorrecto no se pueden devolver por un error de digitación.

¿La página es segura?

¡Claro que sí! Trabajamos con proveedores especializados en Free Fire para garantizar recargas confiables y rápidas. Todas las ventas son finales y, una vez procesada la recarga, no es posible realizar reembolsos debido a la naturaleza del servicio.

¡Tu confianza es nuestra prioridad! 💜
